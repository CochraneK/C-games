# 叮！一起玩 · Bell Together

一个专为双人远程轻量聚会写的静态网页，参考经典德国心脏病（Halli Galli）的 56 张水果牌、恰好 5 颗抢铃规则。所有绘制均为原创 CSS/SVG/Emoji，不使用商业游戏素材。

**试玩页面（GitHub Pages）：** `https://cochranek.github.io/snake-games/bell/`

## 使用方式

- 打开链接 → **创建双人房间** → 复制邀请链接发给朋友。
- 双方进入房间后，轮流按 **翻一张牌**；任一时刻见到两张明牌上某种水果数量**恰好为 5**，立刻按铃。
- **误按**扣 1 张牌；抢铃成功收走双方翻开的牌；一方没有任何牌和可争取的明牌时，本局结束。
- 两人分别按 **开启语音**、授权麦克风，直接边玩边聊；可随时静音。
- 一个人时可按 **单人练习**，与慢速电脑练习，无需信令服务。
- 键盘：`Enter` 翻牌，`Space` 抢铃。

## 设计边界

- Pages 只是静态托管；游戏数据用 **WebRTC DataChannel**，音频用 **WebRTC MediaStream**。
- 默认通过 **PeerJS Cloud** 免费公共服务器交换连接信令；它不是私有语音云服务。PeerJS SDK 从公共 CDN 加载。数据在浏览器间发送，连接失败时不会由 Pages 自动提供服务端中继。
- **需要 HTTPS / 网络可访问性**：某些中国网络、校园网、移动网络或对等 NAT 组合下，STUN 点对点不能成功，语音/对局可能无法使用。此版不配置付费 TURN。正式稳定部署推荐用现有腾讯云部署自有 PeerServer，并提供 TURN 或 TRTC 回退。
- 为降低隐私暴露，玩家不必登录，不采集姓名，也不录音、不储存聊天内容。麦克风只在点击开启并授权后采集；刷新/离开网页会停止。PeerJS 信令仍会接触连接元数据，请勿把随机房间链接公开。
- 客户端只发送「翻牌/抢铃」操作，不接收隐藏牌的顺序；**房主端是牌局权威**。这适合朋友间休闲娱乐，不具备防作弊与高公平性的竞技级保证。
- 抢铃以房主的事件处理为准，并设有 180ms 竞争窗口；窗口内两个玩家都按铃时随机决胜，不能彻底消除网络延迟。
- 房间没有持久保存，刷新房主页面会重置牌局。访客断线时可以重新打开邀请链接尝试重连。新版可增加真正的自动重连、房间密码与服务器仲裁。

## 项目结构

- `index.html` 页面
- `style.css` Less is More 样式
- `game-core.js` 纯函数规则引擎，可运行 Node 测试
- `app.js` 用户交互、PeerJS 实时数据、WebRTC 音频、练习对手
- `tests/core.test.js` 规则单元测试

## 本地预览

```bash
python3 -m http.server 8080
# http://localhost:8080/bell/ （如运行目录为 snake-games 根目录）
node bell/tests/core.test.js
```

本地 `localhost` 上可以测试语音权限；两台设备请使用 GitHub Pages HTTPS 地址，不能直接用普通 HTTP 局域网地址请求麦克风。

## 与现有 snake-games 仓库关系

`bell/` 是一个完全独立子目录。不更改现有贪吃蛇引擎和 `play.html`。当前默认只在页面直达，不自动改首页导航。
